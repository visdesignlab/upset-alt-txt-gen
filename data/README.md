# DATA

This folder contains many example JSON files used for testing the alt-txt generation across various versions of the package and multiple different UpSet grammars. Not every `.json` file in this folder represents a usable state for the most current version of `upset-alt-txt-gen`.

## CSV

The `csv` subfolder contains raw datasets used for supplementary data and resources:

- `D1-covid_symptoms_table.csv` - COVID-19 symptoms data
- `D2-Disease_Data.csv` - Disease information
- `D3-Game of Thrones Characters.csv` - Game of Thrones character relationships
- `D4-Tennis_Data.csv` - Tennis match/player data
- `D5-Country-and-International-org-UpSet.csv` - Country and international organization memberships
